# Spell Casting + Resolution Effects Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `GameState::cast(def_id, controller, target) -> ObjectId` puts a spell on the stack, and when it resolves it DOES something: a creature spell becomes a permanent on the battlefield (ETB), a damage spell marks damage on its target (which the SBA loop then turns into a death). The engine goes from "resolve a placeholder" to "cast a card and the board changes."

**Architecture:** Three changes. (1) `CardDef` gains a data-driven `spell_effect() -> SpellEffect` derivation (in `carddb.rs`): a creature card resolves to a battlefield permanent; a card carrying a new `StaticAbility::DealsDamage { amount }`-style spell marker resolves to dealing damage. (2) `StackObject` (in `priority.rs`) gains a payload — `def_id` and an optional `target: Option<ObjectId>` — so resolution knows what to do and to whom. (3) `GameState` gains `cast(...)` (build a stack object as an object in zone Stack, push it) and resolution logic inside `pass_priority`: when an object resolves, apply its `SpellEffect` — creature → create a battlefield permanent with the caster as controller (ETB, controller set automatically); damage → `mark_damage(target, amount)`. SBAs already run in the 117.5 loop, so a lethally-damaged creature dies on the same pass. This composes every prior slice: stack (holds the spell), priority (resolves it), move/create (puts the permanent into play), characteristics (computes it), SBA (kills lethally-damaged creatures). Mana cost payment, modes, X, counterspells, targeting legality re-check, and the general effect IR are DEFERRED — this is creature-spells + a damage-instant.

**Tech Stack:** Rust 1.93+. No new deps.

**Source spec:** `prior-art/rules-core.md` §601 (casting locks in choices), §608 (resolution), §608.3 (permanent spell becomes a permanent / enters the battlefield). `prior-art/conformance-cases.md` C4-ish (ability independent of source) and the composition of A (ETB) + B (SBA death). Bridges `carddb.rs`, `priority.rs`, `state.rs`.

## Global Constraints

- **Rust edition 2021**, toolchain `1.93+`.
- **Casting choices are fixed when the spell is put on the stack** (CR 601.2): `cast` records the `target` on the `StackObject`; resolution reads it, does not re-choose. (Target legality RE-CHECK at resolution is deferred — this slice assumes the target is still valid.)
- **A creature spell resolving becomes a permanent ENTERING THE BATTLEFIELD** (CR 608.3a) under its controller's control: a fresh battlefield `Object` with `controller = caster`. The spell object (in zone Stack) is removed as it resolves.
- **A damage spell resolving marks damage on its target** (CR 119/120): `mark_damage(target, amount)`. It does NOT directly destroy — the SBA loop (already wired into `pass_priority`) handles lethal damage. The spell object is removed on resolution; instants/sorceries go to the graveyard (modeled by simply removing the stack object — graveyard placement for the cast card is deferred since there is no separate card-in-hand object yet).
- **`spell_effect()` is derived from card data** (creature-ness, the damage marker) — no per-card code; reuse the `CardDef` static-data pattern.
- **Resolution effects compose with SBAs in one pass:** because `pass_priority` already runs `check_state_based_actions` on a full round before resolving, AND resolution happens within that same call, a damage spell that resolves and a creature it kills are handled correctly across the priority loop (the death is caught on the next full round's SBA check — document this ordering).
- **Reuse:** creature permanents enter via the same object-creation path used elsewhere; damage via `Object::mark_damage`; do not hand-roll.
- **TDD**; `cargo test` + `cargo clippy --all-targets -- -D warnings` clean after every task.

```rust
    /// Cast a spell: put it on the stack with its target frozen (CR 601.2).
    /// Mana cost, modes, X, legality checks are deferred. Returns the stack id.
    pub fn cast(
        &mut self,
        def_id: u64,
        controller: PlayerId,
        target: Option<ObjectId>,
    ) -> ObjectId {
        let id = self.minter.mint();
        let obj = crate::priority::StackObject::new(id, controller, def_id, target);
        self.push_stack(obj);
        id
    }

    /// Apply a resolving spell's effect (CR 608). Creature -> battlefield
    /// permanent; damage -> mark damage on the target (SBA handles death).
    fn resolve_effect(&mut self, obj: &crate::priority::StackObject, db: &crate::carddb::CardDb) {
        use crate::carddb::{DefId, SpellEffect};
        let effect = match db.get(DefId(obj.def_id)) {
            Some(def) => def.spell_effect(),
            None => return,
        };
        match effect {
            SpellEffect::ResolveToBattlefield => {
                // CR 608.3a: becomes a permanent entering under the caster's control.
                let new_id =
                    self.create_object(obj.controller, crate::object::Zone::Battlefield, obj.def_id);
                if let Some(o) = self.get_mut(new_id) {
                    o.set_controller(Some(obj.controller));
                }
            }
            SpellEffect::DealDamage { amount } => {
                if let Some(target) = obj.target {
                    if let Some(o) = self.get_mut(target) {
                        if o.zone() == crate::object::Zone::Battlefield {
                            o.mark_damage(amount);
                        }
                    }
                }
            }
            SpellEffect::Fizzle => {}
        }
    }
```

## Out of scope for this plan (deferred to later plans)

1. **Mana cost payment** — `cast` takes no cost; spells are free. The mana system is a later plan.
2. **Targeting legality re-check at resolution (CR 608.2b)** — resolution assumes the target is still valid; a target that left the battlefield is handled only by the `zone() == Battlefield` guard in damage (it silently does nothing), not by countering the spell.
3. **The cast card going to the graveyard** — there is no separate card-in-hand object; `cast` mints the stack object directly. Instant/sorcery → graveyard on resolution (CR 608.2n) is deferred until cards exist in hand.
4. **Modes, X, multiple targets, kicker, additional costs** — single optional target only.
5. **Counterspells / responding to a spell with removal** — the priority loop allows it mechanically (push another spell in response), but no counter effect exists.
6. **ETB triggers, dies triggers** — resolution creates the permanent but fires no triggers.
7. **The general effect IR** — only three `SpellEffect` variants. Activated/triggered abilities, non-damage one-shots, etc. deferred.
8. **Controller-on-ETB for non-spell entries** — `resolve_effect` sets controller for spell-created permanents; the general "set controller = the player who put it onto the battlefield" rule across all entry paths is deferred.

## Self-review notes

- **Spec coverage:** rules-core §608.3a (permanent spell → battlefield) → Task 3 `ResolveToBattlefield`. §601.2 (choices frozen at cast) → Task 2 payload + Task 3 `cast` records target. §608 resolution applies effect → Task 3 `resolve_effect` in `pass_priority`. Damage → SBA death composition → Task 3 `bolt_kills...` + Task 4 integration. Conformance: the bolt+anthem boundary test (Task 4 `anthem_changes_whether_a_bolt_is_lethal`) proves damage interacts with COMPUTED toughness via the existing SBA/characteristics path.
- **Composition:** casting touches every prior subsystem — stack/priority (resolves it), move/create (ETB permanent), characteristics (the entered creature computes its P/T), SBA (lethal damage → death). Task 4 is the proof.
- **Reuse:** ETB permanent via `create_object` + `set_controller`; damage via `mark_damage`; death via the existing SBA loop in `pass_priority`. No hand-rolled zone change or death logic.
